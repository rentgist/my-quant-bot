# ORION 점검 보고 (orion-reports)

PC 예약 작업(orion-check-am / orion-check-pm)이 평일 점검 결과를 `reports/YYYY-MM-DD_am.md`, `reports/YYYY-MM-DD_pm.md`로 올리는 보고 전용 브랜치입니다.
클라우드 루틴이 이 파일을 읽어 CEO 휴대폰으로 요약합니다.

- main에 병합하지 않습니다. 코드·설정 파일을 두지 않습니다.
- 비밀값(API Key 등)과 실제 계좌 금액은 기록하지 않습니다.
- ORION 규칙에 따른 판정 정리이며 투자 추천이 아닙니다.
