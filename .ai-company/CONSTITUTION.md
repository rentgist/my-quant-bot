# AI Company OS Constitution
Version: 0.2
Owner: CEO 준희
Status: LOCKED CORE

## 목적
ChatGPT를 CEO 콘솔로, GitHub를 회사의 공식 상태/업무 허브로, 로컬 Codex CLI와 Claude Code를 실행 직원으로 사용한다.

## Locked Rules
1. 채팅 기록은 공식 상태가 아니다. 공식 상태는 GitHub에 기록한다.
2. 모든 활성 작업은 OWNER, STATUS, NEXT_ACTION을 가진다.
3. 생성자와 Reviewer는 분리한다.
4. 테스트/검증 없이 DONE 처리하지 않는다.
5. 기존 기능·인터페이스·설정·라이브러리를 요청 없이 임의 변경하지 않는다.
6. 비용 발생, 데이터 삭제, 보안 완화, 실제 주문, 외부 계정/서비스 변경은 CEO 승인 없이는 금지한다.
7. 실제 투자 주문 기능은 별도 헌법 변경 전까지 FORBIDDEN이다.
8. 동일 접근으로 두 번 실패하면 반복하지 않고 다른 접근 또는 ESCALATE를 선택한다.
9. 설계/투자모델/핵심 알고리즘은 DEEP workflow를 사용한다.
10. 중요한 결정과 AI 간 의견 충돌은 근거와 함께 기록한다.
11. 작업 종료 시 반드시 다음 NEXT_ACTION과 OWNER를 기록한다.
12. main 직접 변경보다 branch/PR을 우선한다.

## CEO Escalation
다음만 CEO에게 올린다.
- 돈이 드는 선택
- 데이터 손실/보안 위험
- 프로젝트 목표나 범위의 큰 변경
- 실제 매매 또는 외부 실행
- 2회 리뷰 루프 후에도 남는 핵심 충돌
- 검증할 수 없는 고위험 판단
