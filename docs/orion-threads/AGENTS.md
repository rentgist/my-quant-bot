# ORION 작업 지침

이 저장소에서 ORION Threads 콘텐츠를 작성하거나 분석할 때 아래 지침을 따른다.

## 작업 시작

1. `ORION_THREADS.md`를 읽고 계정의 캐릭터와 작성 원칙을 확인한다.
2. `ORION_POST_LOG.md`를 읽고 이미 시도한 후킹, 성과, 다음 실험을 확인한다.
3. 사용자가 제공한 당일 ORION 지표와 시장 데이터를 기준으로 작업한다.

## 짧은 요청의 기본 처리

사용자가 오늘 ORION 데이터를 제공하고 `오늘 글을 써줘`, `오늘 쓰레드 글을 써줘`처럼 짧게 요청하면 아래 작업을 자동으로 수행한다.

1. 파일명을 언급하지 않아도 `AGENTS.md`, `ORION_THREADS.md`, `ORION_POST_LOG.md`를 기준으로 삼는다.
2. 이전 게시물과 실험을 확인하고 같은 실패를 근거 없이 반복하지 않는다.
3. 제공된 데이터를 바탕으로 오늘 가장 중요한 이야기 하나를 선택한다.
4. 메인 포스트 1개와 댓글 약 5개로 구성한 초안을 작성한다.
5. 이야기를 먼저 풀고 데이터는 신뢰도를 높이는 근거로 자연스럽게 넣는다.
6. 실제 포지션이나 전일 신호가 제공되면 오늘 신호와 연결해 서사를 만든다.
7. 최신 시장·정책·지정학 정보가 필요하면 실시간으로 검색해 검증한다.
8. 먼저 게시용 초안만 보여준다. 사용자가 확정하기 전에는 `ORION_POST_LOG.md`를 수정하지 않는다.

핵심 정보가 일부 부족해도 글의 방향을 바꾸지 않는 범위에서는 합리적으로 진행한다. 실제 매매 여부, 신호명처럼 결과를 바꾸는 정보가 없을 때만 짧게 확인한다.

## 정확성과 검증

- 주식, 투자, 거시경제, 지정학 관련 최신 정보는 실시간으로 검색해 검증한다.
- 공식 공시, 거래소, 중앙은행, 정부 기관, 기업 IR 등 최신 1차 자료를 우선한다.
- 사용자가 제공한 ORION 데이터와 외부에서 확인한 사실을 구분한다.
- 확인되지 않은 속보는 사실로 단정하지 않고 `주장`, `보도`, `확인 중`으로 표현한다.
- 숫자, 날짜, 금액, 등락률은 게시 전 다시 확인한다.

## 문체와 캐릭터

- 한국어 반말 문어체를 사용한다: `~다`, `~한다`, `~지`.
- 정중한 존댓말, 과도한 선동, 공포 조장, 흥분한 표현을 피한다.
- 분석적이고 시크하되, 생활 비유와 짧은 반전으로 재치를 만든다.
- 특정 인물이나 코미디언의 문체를 복제하지 않는다.
- 데이터가 주인공이 되지 않게 한다. 이야기를 먼저 만들고 숫자는 판단의 근거로 배치한다.
- 문장은 짧게 쓰고 모바일 화면을 고려해 자주 줄바꿈한다.

## 투자 표현

- 매수와 매도를 단정적으로 권유하지 않는다.
- 실제 포지션은 규모, 진입 조건, 무효화 조건과 함께 설명한다.
- 바닥 확률과 매수 신호를 같은 의미로 취급하지 않는다.
- ORION의 핵심은 예측보다 대응, 수익보다 생존, 확신보다 포지션 크기 조절이다.

## 성과 개선

- 한 번에 여러 변수를 바꾸지 않는다.
- 우선순위는 첫 문장, 게시 시간, CTA 순서다.
- 게시 후 1시간, 6시간, 24시간 성과를 `ORION_POST_LOG.md`에 기록한다.
