# ORION Threads

ORION 트레이더 Threads 계정의 콘텐츠 원칙, 게시물 실험, 성과 기록을 관리한다.

이 문서는 기존 `rentgist/orion-threads` 저장소에서 AI Company OS 통합을 위해 비파괴적으로 이전한 사본이다.

## 문서 구성

- `AGENTS.md`: ORION Threads 작업 원칙
- `ORION_THREADS.md`: 계정 캐릭터, 글쓰기 구조, 후킹과 CTA 전략
- `ORION_POST_LOG.md`: 게시물별 가설, 문구, 성과와 학습 기록

## 운영 원칙

- 실제 투자/시장 로직과 콘텐츠 운영 로직을 구분한다.
- 게시물 확정 전에는 실험 로그를 임의로 갱신하지 않는다.
- 투자·시장 관련 최신 사실은 게시 전에 검증한다.
