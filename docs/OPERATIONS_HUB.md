# QNT 운영 허브

QNT는 ORION의 실행 저장소이면서, 세 제품의 운영 원칙과 검증 기준을 모으는 허브다. 각 제품의 소스 코드는 독립 저장소로 유지한다. 이 문서는 코드 변경과 투자 판단의 기준점이며, 실제 주문을 실행하지 않는다.

| 트랙 | 현재 역할 | 다음 상용화 기준 |
| --- | --- | --- |
| ORION | 한국 시장 중심의 위험·국면·종목 판단 화면 | 데이터 신선도 표시, 재현 가능한 검증, 안전한 `WAIT` 기본값 |
| Microcap | 데이터 수집과 후보 검증 | 수집 품질 감사 → 비용 반영 백테스트 → 소액/모의 검증 |
| Tappaste | MVP 제품 개발 | 구독 흐름, 핵심 사용성, 오류 없는 모바일 경험 |

## 운영 리듬

1. 작업 전: 저장소 상태·최근 테스트·미해결 결정을 확인한다.
2. 작업 중: 한 세션에는 검증 가능한 가장 중요한 변경 한 가지에 집중한다.
3. 작업 후: 완료 내용, 검증 결과, 막힌 점, 다음 첫 작업을 기록한다.
4. 시장 판단: 데이터가 오래되었거나 소스가 불완전하면 새로운 진입 제안 대신 `WAIT`와 재확인을 우선한다.

## 책임 경계

- ORION, Microcap, Tappaste의 소스와 배포는 서로 분리한다.
- QNT의 `docs/`는 공통 운영·검증 기준만 담는다.
- 실제 매수·매도·자동 주문은 이 저장소의 범위가 아니다. 분석·검토와 모의 검증까지만 수행한다.
