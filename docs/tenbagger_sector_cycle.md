# ORION 텐배거 섹터 순환 스캐너

## 목적

이 기능은 10배 상승을 예측하지 않는다. 소형·중형 성장주 중 추가 조사가 필요한 기업을 반복 가능하게 압축하고, 실제 주문은 별도의 ORION 시장 허가와 사용자의 검토에 맡긴다.

## 실행 흐름

1. 평일 09:20 KST에 `TENBAGGER_UNIVERSE`의 다음 섹터 하나를 스캔한다.
2. 핵심 데이터의 절반 이상을 조회하지 못하면 해당 섹터를 완료 처리하지 않고 다음 실행에서 재시도한다.
3. 각 섹터의 상위 연구 후보를 누적한다.
4. 모든 섹터가 완료된 날 14:10 KST에 누적 후보만 정밀 재무정보와 최신 5분 가격으로 다시 평가한다.
5. 최종 후보는 섹터당 최대 3개, 전체 최대 12개를 마지막 정상 결과로 보존한다.

## 평가 구조

- 성장: 매출·이익 성장과 흑자전환
- 수익성: 영업이익률, ROE, Rule of 40
- 회복력: FCF, ROIC, 유동비율, 부채비율, 주식 수 희석
- 밸류에이션: PEG, Forward PER, FCF Yield
- 타이밍: 20·60·120일 추세, 52주 위치, 당일 급락·과열
- 거부권: 핵심 데이터 부족, 극단적 소형주·대형주, 낙하 칼날, 심각한 희석

## 한계

- yfinance·FinanceDataReader 데이터는 지연·누락·정정될 수 있다.
- 현재 재무 데이터는 시점 보존형(point-in-time) 데이터가 아니므로 과거 텐배거 백테스트를 주장하지 않는다.
- 바이오 임상 성공확률, 특허, 경영진 자본배치, TAM과 경쟁우위는 별도 정성 검증이 필요하다.
- 최종 후보는 매수 신호가 아니다. ORION이 STOP·WAIT이면 신규 진입에 사용하지 않는다.
