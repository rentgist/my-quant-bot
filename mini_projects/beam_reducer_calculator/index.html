가정과 식

  • 얇은 렌즈, paraxial approximation
  • 입력/출력 빔은 collimated
  • 두 렌즈 모두 양의 초점거리인 Keplerian 구성
  • 첫 번째(입력측) 렌즈의 초점거리 f1이 주어진다고 가정

M = D_out / D_in, f2 = f1 × M, 축소비 = D_in / D_out, 간격 ≈ f1 + f2

실제 실험에서는 렌즈 두께, 실제 principal plane, 수차, 빔 품질과 입력 빔의 완전한 collimation 여부 때문에 최종 간격을 미세 조정해야 합니다.
