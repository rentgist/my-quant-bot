# 코드 수정 및 검증 워크플로우 규칙

사용자와의 합의에 따라, 앞으로 코드를 수정할 때는 반드시 아래의 3단계 규칙을 엄격하게 준수합니다.

1. **사전 스캔 및 분석 (Pre-scan)**
   - 코드를 수정하기 전에 반드시 iew_file 또는 grep_search 등을 사용하여 원본 코드의 전체 구조와 문맥을 스캔하고 읽어야 합니다.
   - 섣불리 덮어쓰거나 수정 위치를 유추하지 말고, 정확한 위치(예: st.stop() 등 방해 요소 유무)를 파악한 뒤에 작업합니다.

2. **안전한 수정 (Modification)**
   - 코드 수정 시 파이썬 문법 에러나 들여쓰기 문제가 발생하지 않도록 각별히 주의합니다.

3. **사후 검증 및 에러 체크 (Post-verification)**
   - 수정을 마친 후에는 작업을 바로 완료했다고 보고하지 않습니다.
   - 반드시 python -m py_compile <수정된 파일명> 등의 명령어를 통해 문법(Syntax) 에러가 없는지 체크합니다.
   - 로직이 예상치 못한 위치에서 끊기거나 꼬이지 않았는지(예: 렌더링 누락) 최종 확인한 뒤에 사용자에게 작업 완료를 보고합니다.
